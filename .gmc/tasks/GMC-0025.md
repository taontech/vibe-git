实现 Agent 启用状态配置的数据模型与持久化存储接口

### Implementation Scope
- 定义常用 Agent（如 Codex 等）可用性配置的数据模型（包括 `agentId`、`name`、`enabled` 状态）。
- 提供读取与持久化更新 Agent 可用状态的服务/API，支持全量查询与单项更新。
- 设定默认配置机制，未显式配置时默认回退到系统内置的常用 Agent 默认启用列表。

### Acceptance Criteria
- 支持对各 Agent 的可用状态（enabled/disabled）进行读取与持久化落盘。
- 首次启动或无配置项时，能正确加载默认可用状态。
- 接口包含完善的入参校验与异常处理，附带数据层单元测试。
