在任务看板页面过滤不可用 Agent 卡片并停用其状态检测

### Implementation Scope
- 在仓库任务看板/Task 处理页面引入 Agent 可用性配置。
- 改造看板 Agent 卡片渲染逻辑：不可用的 Agent（如禁用的 Codex）不在卡片列表中展示。
- 改造 Agent 状态监测与健康轮询逻辑：对已停用的 Agent，阻断或跳过其状态查询请求与周期性检测定时器。

### Acceptance Criteria
- 任务看板页面仅展示处于可用状态的 Agent 卡片；被禁用的 Agent 卡片完全隐藏。
- 禁用 Agent 后，网络请求或后台轮询中不再产生该 Agent 的状态检测请求。
- 当 Agent 重新启用后，看板可正确恢复渲染其卡片并重新启动状态检测。

### Dependencies & Merge Risks
- 依赖配置读取接口。主要修改任务看板渲染与 Agent 状态轮询模块，与设置 UI 解耦。
