在设置页面新增常用 Agent 启用/禁用配置界面

### Implementation Scope
- 在系统设置页面中增加「可用 Agent 管理」配置区域。
- 为常用 Agent 列表（如 Codex 及其他支持的 agents）渲染开关或复选框组件，呈现当前可用状态。
- 对接配置获取与保存接口，用户切换状态时触发持久化保存并提示保存结果。

### Acceptance Criteria
- 用户可以在设置页面直观查看所有常用 Agent 的启用/禁用状态。
- 切换任意 Agent 开关均可成功持久化更新状态。
- 提供加载中与保存成功/失败的状态反馈。

### Dependencies & Merge Risks
- 依赖配置模型与存储接口。改动限定在设置模块前端代码，与其他页面无代码冲突。
